Language

Small syntax, deliberate control.

@{SPL/1}

Protocol header

Marks a message as SPL and begins an SPL conversation.

$>

Block start

Introduces a pseudocode block. Commands run in their written order.

$variable

Variable

References a session-wide value declared with let.

'quoted text'

Literal text

Natural language inside a pseudocode block is quoted.

Operators: combine conditions with & (and), | (or), and ! (not).

Reference

Core commands.

CommandPurposeExample
enforceSets a non-negotiable requirement.enforce 'Use plain language.'
forbidProhibits behavior in the response.forbid 'Reveal internal reasoning.'
assertChecks a condition and emits a failure if it is false.assert 'ready' -> 'Not ready.'
failIndicates an SPL failure.fail 'Missing configuration.'
outGenerates output, optionally constraining length and schema.out{sch='array'} 'List fruits.'
elicitRequests information from the user.elicit 'Which language?'
thinkDeliberates before producing a result.think{level='high'} 'Find the cause.'
letDeclares an immutable session-wide variable.let $name = 'Ada'

Control flow and data

Guide a response step by step.

Branch and iterate

Use if/else for conditional instructions, while to continue while a condition holds, and for to work through a range or collection.

Keep session context

let stores JSON-native strings, numbers, booleans, arrays, and objects. Variables are immutable for the session and can be interpolated in pseudocode.

$> let $audience = ['developers', 'writers']
for $i in 0..2:
    out{len=sentence, sch='string'} "Write tip $i for $audience."

Examples

Constraints

Source
@{SPL/1}

$> enforce 'Use plain language suitable for a first-time developer.'
forbid 'Mention implementation details or internal reasoning.'
out{len=75, sch='string'} 'Explain what a variable is in JavaScript.'

Conditional status

Source
@{SPL/1}

$> if 'build is green':
    out{len=sentence, sch='string'} 'Report that the build passed.'
else:
    think{level='high'} 'Identify the likely cause.'
    out{len=paragraph, sch='string'} 'Summarize the next step.'

Failure responses

Failures have a consistent shape.

When an assertion or condition is not met, SPL can return a standardized failure response.

@{SPL/1}
{
  "status": "failure",
  "reason": "Description of the failure"
}
