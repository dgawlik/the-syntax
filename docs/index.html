Semantic Prompt Language

Make LLM instructions
compact, explicit, and repeatable.

SPL/2 is a strict, session-scoped language for turning natural-language intent into structured requests that people can read and models can execute consistently.

Breaking change: SPL/2 replaces SPL/1.0 with a denser grammar. See the migration guide before upgrading.

Why SPL

Natural language is powerful.
It is not a protocol.

01

Make intent inspectable

Separate task, inputs, method, quality criteria, output contract, and evidence instead of burying them in a prose prompt.

02

Reduce prompt drift

Explicit bindings, imports, and exports make multi-turn work reproducible without silently relying on chat history.

03

Protect source boundaries

Inert data literals distinguish untrusted source content from executable instructions.

04

Get usable failures

Typed clarify, conflict, invalid, and refuse outcomes replace success-shaped guesses.

SPL/2 migration

Compact syntax.
Deliberate breaking change.

SPL/2 rejects SPL/1.0 requests rather than accepting ambiguous aliases. Update both the request marker and every compacted token.
