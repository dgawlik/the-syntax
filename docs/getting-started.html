Getting started

Copy one file, add one marker, and start scripting.

1. Install the agent

The repository contains agent/spl.agent.md. Copy it as-is into your project's .github/agents/ folder (a copy is already there in this repository) and select the spl agent in VS Code Copilot Chat.

The agent's front matter configures the model and the tools SPL statements may call:

---
name: spl
description: A dense, session-scoped protocol for expressing LLM instructions, state, ...
model: GPT-5.6 Terra (copilot)
tools: [vscode, execute, read, edit, search, 'github/*', todo]
---

Adjust model and tools to what you have available. Tool calls to tools not listed fail with Tool <name> not available.

2. Activate SPL

Start a message with @{SPL/1}. From then on the whole chat thread is in SPL mode, so later messages do not need to repeat the marker.

@{SPL/1}
$>
let $user = 'Alice'
out{len='one sentence'} 'Greet $user'
<$

The response is just the greeting – no echoed pseudocode, no marker, no preamble.

3. Mix prose and blocks

A message can interleave plain-language instructions with pseudocode blocks. Prose is general guidance; blocks are executed top to bottom.

@{SPL/1}

Be friendly and brief.

$>
let $city = 'Paris'
out 'Name one landmark of $city in one sentence'
<$

$> out 'Name a food typical of $city in one sentence'

Variables persist, so the second block can use $city (and it could be sent in a later message).

4. Handle failures

If an assert fails or a statement errors, all output is discarded and the reply is a single JSON failure envelope:

@{SPL/1}
$>
let $retries = 5
assert $retries < 3 -> 'Too many retries'
out 'Should not appear'
<$
{
  "spl": "1.0",
  "status": "failure",
  "reason": "Too many retries",
  "statement": "assert $retries < 3 -> 'Too many retries'"
}

5. Leave SPL mode

Send a message starting with @{SPL/off}. All variables, functions and constraints are discarded and later messages are plain natural language. A later @{SPL/1} starts a fresh session.

6. Editor support

Install the VS Code extension for syntax highlighting of .spl files and ```spl fences – see Tooling & testing.

FormExample
Single statement$> out 'Hello' – ends with the statement (and its indented body)
Multi-line block$> alone on a line, statements, then <$ (if omitted, the block runs to the end of the message)
Comments# to end of line (outside strings)
Strings'single' or "double", escapes \' \" \\ \$
